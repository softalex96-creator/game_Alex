Политика конфиденциальности

Здесь описано, какие данные используются в демонстрационной версии LevelUp и зачем они нужны для работы личного кабинета.

Это черновая политика для этапа разработки. До запуска продаж её необходимо дополнить реквизитами оператора, сроками хранения и проверить у юриста по применимому праву.

1. Какие данные используются

При входе через Google LevelUp получает только данные, которые возвращает выбранный провайдер: отображаемое имя, адрес электронной почты и, если он доступен, аватар. При входе через Steam может использоваться идентификатор Steam и открытые сведения профиля, необходимые для входа.

Заявки и обращения поддержки в текущей версии сохраняются локально в браузере пользователя. Данные банковских карт сайт не запрашивает и не принимает.

2. Для чего это нужно

  • показать профиль в личном кабинете;
  • связать локальные заявки и обращения с вошедшим пользователем;
  • обеспечить безопасный вход через выбранного провайдера.

3. Сервисы, участвующие в работе

Для авторизации применяются Firebase Authentication и Google. Вход через Steam выполняется через Steam и техническую серверную прослойку. Эти сервисы обрабатывают данные по собственным правилам конфиденциальности.

4. Хранение и защита

Данные заявок и обращений в этой демоверсии остаются в используемом браузере до очистки данных сайта. Настоящее хранение заказов и платежей будет подключено только после отдельного запуска защищённой серверной части.

5. Ваши вопросы

Чтобы уточнить, какие данные отображаются в кабинете, или попросить их удалить из браузера, воспользуйтесь контактами на странице «Контактные данные».
