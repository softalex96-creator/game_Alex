# LevelUp — стартовый MVP

Небольшой одностраничный сайт-витрина для продажи онлайн-игр и игровой валюты в СНГ.

## Что уже есть

- главная страница с каталогом игровых товаров;
- блок о работе в Кыргызстане и будущем запуске в России;
- адаптация для телефона;
- личный кабинет с подключённой оплатой и статусами заказов.

## Как посмотреть

Откройте файл `index.html` двойным щелчком в браузере.

## Что подключать следующим этапом

1. Купить домен и опубликовать сайт через GitHub Pages.
2. Уточнить реальный каталог, цены и условия возврата.
3. Выбрать безопасный сервис авторизации для личного кабинета.
4. Выбрать платёжного провайдера, который работает в нужных странах.

До этих настроек сайт не должен собирать пароли, паспортные данные и данные банковских карт.
